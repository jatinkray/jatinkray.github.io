Rules I hold agents to

  1. Humans approve changes.Agents investigate on their own. Remediation waits for on-call sign-off.
  2. Access is governed.Agents reach telemetry only through governed MCP tools, never with raw credentials.
  3. Evidence comes first.Every hypothesis links to the metrics, logs and traces behind it.
  4. Telemetry stays affordable.Agents need history. Tiering and columnar storage keep it cheap enough to retain.

Build 01 · Observability engine · Rust · Apache-2.0

Parqtel

A lightweight observability engine. OTLP metrics, logs and traces are stored as compressed Parquet, queried through a Prometheus-compatible API, with built-in alerting and seven MCP tool servers for AI-driven incident response.

Rust · AxumOTLP gRPC/HTTPParquet + ZstdPromQL-compatibleHelm OCICosign + SBOM

  • 10k/ssustained ingest on a 10M-sample benchmark, zero errors
  • 12.7 msinstant query p50; p99 range query 160 ms
  • ~15 MBsingle static binary in a distroless image
  • 10–20×compression with columnar Parquet + Zstd
  • Drop-in for Grafana. Instant and range PromQL queries, so existing dashboards work unmodified.
  • Built for agents. MCP servers give LLM agents governed access to telemetry for automated root-cause analysis.
  • Hardened supply chain. Cosign-signed releases, SBOM, Trivy, CodeQL, OpenSSF Scorecard and no unsafe Rust.
